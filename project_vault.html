Hardware Flashing Guide & Protocol Details

ESP32: Implements genuine SLIP packet framing connecting directly to the ROM bootloader at 115200 baud. If sync times out, hold the BOOT button and press RESET before flashing.

Arduino Uno / Nano: Uses the STK500v1 protocol with 128-byte page programming over USB-UART. The browser issues a DTR toggle pulse to reset the board into bootloader mode.

Raspberry Pi Pico / RP2040: Uses USB mass-storage drag-and-drop. Hold BOOTSEL while plugging into USB, then copy your .uf2 file to the virtual drive.
